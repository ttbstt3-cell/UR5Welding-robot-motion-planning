# 连续化QP数值条件与TCP内部约束灵敏度比较

2026-10-19。全部实验位于本隔离目录；**正式优化器、正式阈值、验收、模型、TCP、ROS链路、Home与HMI当前索引均未修改**。没有发送运动，没有导出正式优化轨迹/执行许可，`executionReady=false`。

## 决策结论

当前证据支持**先修复连续化的时间参考和细分节点一致性，不放宽0.5mm门，不直接换求解器**。

数值等价变换确实降低Hessian条件数、缩短本输入的失败求解耗时，但无法使当前约束组合可行。诊断副本放大TCP内部约束可以使QP收敛，却仍未通过正式几何精度。QP收敛不等于整任务可执行。

## 3. 隔离TCP内部约束灵敏度

正式最终门始终为位置轮廓<0.5mm、同步<0.5mm、姿态≤0.5°；**以下改变仅发生在隔离问题的TCP不等式右端，不改真实TCP或正式文件**。速度/加速度、关节限位、Q/P/t、目标函数等不变。

### 首次QP

- 姿态固定0.46°，位置内部约束依次0.40/0.46/0.49/0.50/0.55/0.65mm：LP均未找到可行解（0/6）。
- 位置固定0.46mm，仅改变姿态为相同数值的度：LP均未找到可行解（0/6）。
- 同时改变两项至0.46/0.49/0.50/0.55/0.65/0.8/1/2（单位分别mm和°）：均未找到解；两项数值为5时LP可行。它们是不同单位的共同数值扫描，不能解释为同一种物理误差。
- 共同数值最小约3.842772；更可解释的单因素LP：**姿态保持0.46°，位置最小内部界约3.972748994mm**，原始矩阵残差5.15e-12。该值只针对当前FK线性化，不证明全部非线性机器人规划无解，也不是建议的新门限。

原单因素最小界辅助LP上界2，因此记录为-2；不能把它解释成“任意位置界都无解”。后续`minimum_position_attribution.json`将诊断辅助上界设为10，得到上述3.972749mm。末次最小界辅助LP达到90秒预算，保留为UNKNOWN/预算退出，不冒称不可行。

## 4. 两个明确的建模问题

### A. 返回Home减速与匀速时间参考不一致

单因素最小界LP的主要活跃行集中在原始边359（exit），u=5/6附近，证据见`minimum_position_attribution.json`。

- 该段TCP跨度43.284563mm，时间0.609492s。
- 控制器曲线强制末端六轴速度全零；目标由`interpolate_tcp_pose_slerp`在每段按时间比例做位置线性插值，意味着最后一段仍有约71.0mm/s的匀速参考直到终点。
- 原种子最大同步误差6.431394mm出现在此段u≈0.67。
- 在当前线性化、其余约束不变时，位置0.46mm不可行，最小需约3.97mm。单纯换求解器、改权重或放宽姿态不能消除这一冲突。

这是时间参考/末端减速建模的证据，不是修改硬件限值的依据。下一步应统一物理合理的路径进度s(t)、首尾静止条件、节点时间和期望TCP，再用原误差门检查；不能把期望轨迹事后改成实际FK来人为消除误差。

### B. 关节线性细分破坏笛卡尔目标一致性

`optimize_hmi_controller_continuity/subdivide`分别使用关节线性插值得新q，用Cartesian位置线性+SLERP得新目标；一般情况下`FK(interp(q)) != interp(FK(q))`。

- 360个原始节点最大位置误差仅0.000140118mm。
- 新增717节点中，178个固定节点位置误差>0.5mm；所有超差节点都是新增点。
- 最大固定节点误差0.637526782mm，approach节点135，t=4.361438866s。
- Hermite在节点时刻严格等于节点q，速度不可能改变该时刻的FK。因此，保持这些新增q与目标不变，已不可能通过正式0.5mm门；这不是QP数值精度问题。

单纯继续拆关节直线或提高QP预算，会重复求解并放大数据，不会修复固定节点。应在后续获准重构时用与目标一致的局部笛卡尔/连续IK细化，保留原47焊接目标及原节点，新增节点逐个验收，并完整重做节点/边/插值碰撞。不能只把目标改成错误q的FK。

## 5. 推荐下一步，不在本轮直接集成

1. 先加固定节点精度预检：若节点本身超差，精确报告并停止速度优化，避免大QP重复计算；这是提前发现失败，不是放宽或跳过验收。
2. 修复细分节点的q/Cartesian目标一致性，再处理首尾静止与时间参考；不重做CBi-RRT*/ACCP搜索框架。
3. 保留本轮等价缩放、精确消元、phase-I可行性和有界求解策略作数值候选。优化目标之前先确认该线性化可行；区分不可行、预算退出、数值问题。
4. 自由空间和焊接段对同步参考的物理含义若需分别建模，应显式定义并经用户决定，不能擅自免除当前0.5mm要求。
5. 仅在这些语义修复后，重新做原门限下的全任务控制器等价/碰撞/限位/版本验证。当前继续`executionReady=false`。
