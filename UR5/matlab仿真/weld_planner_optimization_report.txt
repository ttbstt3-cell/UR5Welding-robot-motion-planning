UR5 80-point weld planner optimization benchmark
Date: 2026-09-23

Scope
-----
Only MATLAB planning was measured. No ROS2 command was published, no real
robot was moved, and the CoppeliaSim scene/TCP calibration were not changed.

Profiler diagnosis
------------------
The fresh profiled baseline took 672.732 s of algorithm time (profiler wall
time 676.762 s). The largest costs were:
  localGenerateLayer                       658.869 s
  generate_actual_axis_ik_candidates       658.441 s
  inverseKinematics.stepImpl               292.792 s
  inverseKinematics.solve                  288.084 s
  rigidBody.rigidBody construction         194.318 s
  IKHelpers.computeCost                    188.465 s
  localJointLimits                         168.784 s
  inverseKinematics constructor            135.267 s

The optimized profiled run took 346.143 s of algorithm time (350.343 s wall).
The stable fast configuration reuses one inverseKinematics solver and one
joint-limit vector, caches accepted candidates for repeated exact poses, and
uses Lazy collision only for interior samples of graph edges. Node collision
checks remain eager, so colliding IK states never enter the layered graph.

Important experiment result
---------------------------
An additional continuation-seed experiment was tested, but it retained too
many fine-refinement states (1756 states), failed to form a complete path, and
took 997.286 s. It is therefore disabled in the stable fast profile:
  profile_weld_actual_axis_fast.m -> reusePoseCandidates = false
