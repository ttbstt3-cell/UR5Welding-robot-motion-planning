## 2. 仿真启动

先启动 CoppeliaSim：

```bash
cd /opt/coppeliaSim
source /opt/ros/humble/setup.bash
./coppeliaSim -f /home/ttbstt/jixiebi/UR5/ur5.ttt
```

再启动外部控制节点：

```bash
cd /home/ttbstt/jixiebi/ros2_ws
source /opt/ros/humble/setup.bash
source install/setup.bash
ros2 run ur5_controller controller --ros-args -p send_demo:=false
```

MATLAB 场景检查：

```matlab
addpath('/home/ttbstt/jixiebi/UR5/matlab仿真');
run('/home/ttbstt/jixiebi/UR5/matlab仿真/sync_ur5_joint_states.m');
```

```text

```

## 4. HMI 启动和预演

```bash
source /opt/ros/humble/setup.bash
cd /home/ttbstt/jixiebi/UR5/ur5_hmi
./run_hmi.sh
```

推荐流程：

```text
读取实时状态
→ 选择任务
→ 选择自由空间算法（焊缝段固定 ACCP）
→ 开始规划
→ 验证轨迹
→ 3D 预演
→ Final Execution Check
→ 人工确认后才考虑执行
```

## 5. 轨迹数据约定

- 关节路径：`N×6`；
- 单位：MATLAB 规划层使用 rad；
- ROS/URDF 关节顺序：`shoulder_pan_joint`、`shoulder_lift_joint`、`elbow_joint`、
  `wrist_1_joint`、`wrist_2_joint`、`wrist_3_joint`；
- 不对连续轨迹逐点 `wrapToPi`；需要换分支时只允许对整列施加同一个 `2π*k`；
- HMI 轨迹必须包含时间或明确经过时间参数化；
- 轨迹必须带碰撞验证、TCP/工件/URDF 版本绑定元数据。
