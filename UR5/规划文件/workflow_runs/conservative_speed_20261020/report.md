- 新连续规划：`在线规划 → 新连续规划输出速度（默认50%）`。启动默认50%，在唯一最终验收之前缩放一次；不重复两遍完整验收。
- 已有文件：`轨迹执行 → 文件调速：生成新轨迹并完整离线验收`。选择相对当前文件的1%～100%，点击“生成调速版并完整验收”。
- 227秒原文件默认50%。**已载入降速文件时，文件调速默认100%保持当前速度**，防止454秒再次误变908秒；100%不生成重复文件。用户仍可明确选择更慢比例。
- 新连续规划的默认50%与当前文件调速100%互相独立；预演倍速、点动速度、运行时示教器倍率也独立。

- 所有源文件/版本检查与最终真机软件门保持。失败不发布新文件、不把局部/离线PASS标为物理/伺服PASS。
- 新连续规划默认50%是相对本次计算结果的速度比例，不是任意新场景都保证可执行的物理认证。

原HMI实例没有强制关闭或重启；在没有活动真机任务时重开才能显示新控件。旧实例也可手动导入已生成的454秒MAT，但不会自动收到外部进程的载入事件。
