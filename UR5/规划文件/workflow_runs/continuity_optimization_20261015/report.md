# 完整轨迹连续性诊断与优化（2026-10-15）

本报告为离线验证结果。没有连接 ROS action、没有切换控制器、没有发送机器人运动，也没有生成 `trajectory_execute_ready.*`。

## 结果

原始完整轨迹（接近 165 点、焊接 47 点、退出 147 点，去重后 357 点）在控制器等价 cubic Hermite 验证中为：

- TCP 时间同步最大误差：2.816926 mm
- 姿态最大误差：0.760377°
- TCP 轮廓最大误差：未通过

误差峰值主要在接近段起步和焊接段高姿态变化区；不是 CBi-RRT* 或 ACCP 的离散目标错误，也不是 J6 圈数接口跳变。

固定 47 个 ACCP 焊接节点及其 TCP 目标不变，新增 57 个仅用于执行插值的自由空间节点，并采用局部时间分配 + 节点速度优化。最终离线候选为 414 个节点：

- TCP 时间同步最大误差：**0.461499 mm，PASS**
- TCP 轮廓最大误差：**0.224258 mm，PASS**
- 姿态最大误差：**0.459695°，PASS**
- 最大关节速度：**0.0819511 rad/s，PASS**（限制 0.0872665）
- 最大关节加速度：**0.259982 rad/s²，PASS**（限制 0.261799）
- 节点/段内最大 jerk：4.244388 rad/s³；RMS jerk：0.175377 rad/s³
- 最大节点加速度跳变：0.395181 rad/s²；两个接近/焊接和焊接/退出接口已执行 C² 接口约束并通过
- 41301 个控制器等价采样点：关节限位 PASS、全程自碰撞/焊枪/焊丝/工件/地面环境碰撞 PASS
- 最小有限正碰撞间隙：0.193050 mm。该值是模型采样距离，不是经过物理测量的安全余量证明。
- 总时间：255.040840 s；接近/焊接/退出分别 119.204087 / 31.398255 / 104.438497 s

## 最大误差定位

最终候选的同步误差峰值位于全局时间 **146.384213 s**、焊接段内部第 235 条插值边、`u=0.23`：

`q_deg = [-81.754487, -55.128089, 47.116167, -73.471554, -87.803272, -4.281791]`，位置误差 0.461499 mm，姿态误差 0.110977°。

姿态误差峰值位于全局时间 **134.311837 s**、焊接段内部第 222 条插值边、`u=0.77`：

`q_deg = [-93.834343, -57.827529, 57.059252, -73.733916, -66.188566, 1.448000]`，位置误差 0.292980 mm，姿态误差 0.459695°。

优化前峰值分别为 23.351721 s（同步 0.568271 mm）和 12.519871 s（姿态 0.548976°，均按焊接段局部时间计）。因此原始问题是节点速度/时间分配造成的 cubic Hermite 插值误差，优化后仍由焊接段的关节空间到笛卡尔映射产生峰值；没有发现 TCP、碰撞模型或三段接口的几何不连续。

## J6 长旋转

接口修复保留实际数值关节路径，没有取模或强制最短角。接近段仍包含约 **329.109496°** 的 J6 实际旋转；完整候选 J6 数值范围为 -125.319356° 到 203.790140°，累计绝对运动约 921.862300°（接近、焊接、退出合计）。在 5°/s 的速度上限下，仅这段 329° 旋转的速度下界约 65.822 s；因此较长总时间是实际关节运动约束的结果，不能用 ±2π 替换来缩短。该长边已按实际数值插值并重新做碰撞/限位审计。

## 控制器依据

本机只读快照显示目标控制器为 `scaled_joint_trajectory_controller`，参数为 position command、position+velocity state、`interpolation_method=splines`、125 Hz、允许非零末速度。ROS2 joint trajectory controller 安装头文件明确说明 positions+velocities 使用 cubic spline；HMI 发送接口会保留 `time_from_start` 与 `velocities`（见 `UR5/ur5_hmi/trajectory/trajectory_utils.py:208`）。因此本报告按 positions+velocities 的 cubic Hermite 进行离线等价验证，没有假设 UR 控制器会自动消除误差。实际伺服跟踪响应仍未在真机运动中验证。

## 保持不变与执行状态

- CBi-RRT*、ACCP-D、IK、47 个焊接目标、TCP、焊枪/焊丝/工件/地面碰撞模型、碰撞过滤和阈值均未改变。
- 原 47 个焊接 `q` 节点和 TCP 目标逐值保持；新增节点只用于自由空间执行插值，不能替代规划目标。
- 版本依赖快照在审计前后 SHA 一致，没有 STALE。
- 数值审计结果 `complete=true`，但 `executionReady=false`：模型最小间隙仍需独立安全余量确认，控制器目前没有进行真实伺服响应试验，且 wire_collision_shorten_mm=3 mm 仍是近似参数。
