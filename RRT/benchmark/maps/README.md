# Phase 10 benchmark maps

`phase10Maps.m` is the single fixed source for the four 2-D benchmark maps.

- Workspace: `[0,100] x [0,100]`
- Start: `[10,10]`
- Goal: `[90,90]`
- Clearance: `0`

The map obstacles are deterministic axis-aligned rectangles. No benchmark run
samples or regenerates obstacles.
