## 当前结论

1. 连续焊缝规划的正式算法是 **ACCP**。
2. 自由空间接近/退出使用关节空间 RRT 系列；HMI 当前默认入口是
   `Constraint-aware Bidirectional RRT* (CBi-RRT*)`，可选 `RRT`、`RRT-Connect`、`Bi-RRT*`。
3. CoppeliaSim 仿真链路为 MATLAB → `/joint_trajectory` → 外部 `rclpy` → ZMQ Remote API → CoppeliaSim。
4. HMI 是真机侧的状态、标定、轨迹预演和安全门控界面；它不会绕过 MATLAB 规划结果直接生成路径。
5. 当前冻结仿真场景已经完成离线碰撞与连续性验证；真实 TCP、真实工件位姿和真实焊枪安装几何仍需统一验收，
   因此真实焊接执行保持阻断。

相关源代码也已按模块复制到 `源码副本/`，但实际运行源仍是项目原始目录；副本只用于阅读、
审阅和交接。

## 重要原则

- 不修改稳定的 ROS2 控制链路，除非用户明确要求。
- 不恢复 CoppeliaSim 内嵌 Python `simROS2` subscriber；CoppeliaSim 只发布 `/joint_states`。
- TCP、工件、焊枪安装版本改变后，旧轨迹必须重新验证并标记为过期。
- 任何真机执行必须经过实时反馈、起点误差、控制器、安全状态、碰撞元数据和人工确认门。
