previous qPath or state graph.  No ROS2 command, real-robot motion, or
CoppeliaSim scene change was made.

Algorithm design
----------------
  - Point 1: only a small cold-start seed set is used.
  - Points 2..80: previous joint state plus local velocity prediction are
    used as IK seeds.
  - Local roll/travel neighborhoods are limited to 9 pose candidates.
  - J4/J5/J6 local perturbations are limited to 3 degree-class seeds.
  - The beam is explicitly limited to one state in the fastest run.
  - Every accepted node performs full robot/environment and self-collision
    checks, including the MATLAB wire cylinder.
  - Every retained adjacent edge performs dense joint interpolation and
    complete collision checks.  TCP deviation is independently sampled and
    reported; it is not hidden by node-only errors.
  - If enabled, the original layered planner is a fresh-scene fallback; it
    is disabled in the reported beam=1 benchmark to keep the timing fair.

Analytical IK check
-------------------
MATLAB R2025b `analyticalInverseKinematics` was tested on the loaded
`universalUR5` model.  The object is available, but:

  IsValidGroupForIK = 0
  KinematicGroupType = RRRRRR

Therefore closed-form UR5 IK cannot be substituted directly without first
building a supported, calibration-consistent UR5 kinematic group.  The
experiment keeps the validated numeric IK solver.

Remaining bottleneck and 8-second target
----------------------------------------
At beam=1, IK takes 9.686 s and the complete algorithm takes 16.836 s.
The remaining approximately 7 s includes full collision checks, layered
edge validation, TCP segment-error validation and MATLAB object overhead.
An 8-second target would require optimizing collision/object operations or
using a calibration-consistent closed-form IK implementation; it must not
be reached by skipping node/edge checks or reducing the 80 points.
