# 连续规划重构：先独立验证，再接生产

已阅读AGENT_HANDOFF.md最新10月19记录、相关C/Hybrid-D历史及当前源码；文档首部旧仿真说明不能覆盖末尾真实场景状态。

## 旧调用关系

`prepare_hmi_continuous_request`
→ deferred weld timing(Adaptive Time Scaling)
→ 边界Cartesian transition（有缺口时）
→ generate C（A/B作参考、C密集审计）
→ C失败则controller-aware weld QP；C成功则Hybrid-D（6次尝试）
→ D失败保存C回退
→ merge
→ global continuity：4轮QP+关节/Cartesian分别细分
→ 4轮重定时QP
→ 再次接口C² QP
→ 最终controller等价碰撞/FK/解析极值
→ 版本/准入
→ 离线输出。

问题：多个模块反复修改同一时间/速度；细分后固定节点与参考不一致；末段零速度与线性时间参考冲突；部分成功不等于整个任务成功。

## 三阶段单向所有权

1. **Geometry**：固定原节点/原TCP目标。建立单一可微几何曲线q(s)，独立原始Cartesian/SLERP参考P(s)。必要时只在本阶段新增局部IK节点；原47焊接节点不变。若超预算/不可行，停止，不交给速度器修几何。
2. **Parameterization**：q(s)、P(s)冻结。统一生成单调、首尾静止的s(t)及q/速度；只从同一曲线采样执行节点，目标来自预先确定P(s(t))。明确有界控制器离散化预算；小型解析接口C²兼容修正由本模块独占。解析导数限值决定时间，不再交给多个优化器互相覆盖。
3. **Acceptance**：只读最终P+V三次Hermite。原0.5mm/0.5°、解析速度/加速度/关节位置极值、完整101点/边且>=5000、原碰撞规则、版本和场景门。失败不能反向改目标/放宽门；不授予执行许可。

独立主方法：几何C²样条+局部Cartesian IK一致性细化；单调局部时间时钟与首尾静止的五次几何进度复合；解析导数与控制器等价离散验证。全局统一倍率原型虽数值PASS，但历史轨迹运动时长1749s，已经拒绝，不接生产。局部时间分配后325s。计时与速度只由第二阶段修改，参考来自冻结原Cartesian目标及事前声明的时钟，不来自候选实际FK。

不自动采用停走逐点轨迹，不删原C/D/QP。几何细化最多6轮、1800节点、150秒；时间模块最多12轮、2400节点。原47个焊接q及TCP目标逐值保留。原始共享关节节点可能携带独立FK计算产生的微小不同TCP矩阵，边界以原ACCP目标为准，不改47个目标。新增几何点先IK+限位+原生场景碰撞，最终全部控制器边仍做完整审计。

控制器实际输出仅P+V，不能导出诊断加速度字段令ROS改用五次插值。C²只承诺三段接口及静止首尾，其他节点加速度跳变、段内jerk单独报告；不声称整体C²或jerk全局最优。焊接进给速度为非恒定，必须另做工艺验证。

最终验收使用已有`check_scene_environment_collision`和self skip，不使用遗漏固定安装接触策略的通用裸环境检查。没有新增底座、枪、丝或工件过滤例外。

当前配置请求的40rad/s²只是先前控制器配置来源上界，不是当前负载认证。新副本峰值14.47rad/s²、jerk1600rad/s³必须明确报告；现有实际执行检查仍以PAYLOAD_ACCELERATION_PENDING拒绝，不能由离线PASS替代。
