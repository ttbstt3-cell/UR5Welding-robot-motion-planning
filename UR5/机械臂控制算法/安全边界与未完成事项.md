## 当前不能直接宣称完成的内容

### 1. 真实 TCP 尚未与 MATLAB 规划 TCP 统一

最新只读诊断显示控制器当前 TCP 与 HMI 已应用规划 TCP 存在约 `35.197 mm` 的位置差异。
控制器 `tcp_offset` 的 tool-output/flange 表示不能直接当作 MATLAB `tool0` 偏移。

在现场确认以下内容前，不得把真实 TCP 数据自动写入冻结 MATLAB 场景：

- 示教器 TCP 参考点是否确实是焊丝/导电嘴尖端；
- UR flange、tool0、MATLAB tool0 和 `WeldTCP` 的完整变换；
- 导电嘴中心、焊丝轴线和伸出长度；
- 焊枪相对 J6 的真实安装角。

### 2. 焊丝碰撞几何仍需实物确认

当前 MATLAB 使用 `wireCollision` 细圆柱作为碰撞代理。历史记录为约 18 mm 长、1.2 mm
直径，但该数值尚未完成实物测量验收。不能用 GunCollisionHull 最近顶点代替真实导电嘴中心。

### 3. 真实工件标定与冻结仿真工件不同

冻结仿真工件原点与最新实测工件原点相差约 `444.146 mm`。真实工件位姿没有经过完整
质量门并注入 MATLAB 碰撞场景前，冻结仿真中的 `qPreWeld/qPostWeld` 不能用于真实工件。

### 4. 真机执行尚未完成验收

当前只能进行：

- 只读关节/TCP 状态检查；

- MATLAB/HMI 离线规划和预演。

真机执行必须按以下顺序：


在 TCP/工件/焊枪安装版本未统一前，Final Execution Check 必须保持 BLOCKED。

- 不修改 `controller.py`、ROS2 topic、CoppeliaSim `functional.lua` 和稳定控制链路；
- 不覆盖 `ur5_tool_calibration.mat`、`scene_geometry.json` 和已经验收的 MAT 结果；
- 修改前先备份；修改后记录日期、文件、参数、验证方式和回滚位置到
  [`AGENT_HANDOFF.md`](</home/ttbstt/jixiebi/AGENT_HANDOFF.md>)；
- 新算法实验使用独立入口和独立输出目录，不覆盖稳定基线；
- 仿真 PASS、HMI 轨迹验证 PASS、真实机器人可执行三者必须分开表述。

## 源码副本的安全边界

`机械臂控制算法/源码副本/` 中的文件是交接快照，不是第二套控制系统。尤其注意：

- 不要把副本目录加入 MATLAB 的默认 `addpath` 后直接运行；
- 不要从副本目录启动 HMI、ROS2 节点或 CoppeliaSim 控制；
- 不要在副本中生成/覆盖实验结果来代替原始 `results` 或 `planning_runs`；
- 任何源代码修复必须回到原始工程完成，再重新生成新的交接副本；
- 副本与运行源的差异必须记录在 `AGENT_HANDOFF.md` 中。

这项限制是为了避免 MATLAB 同名函数、HMI 相对路径和 ROS2 包路径发生 shadowing，
也避免误把归档代码当成已经验收的真实机器人控制代码。
