# Point1 WireCollision长度敏感性诊断

本次仅增加并测试 `wire_collision_shorten_mm`。它在每次离线场景副本中重建
`WeldingGunWire` 的 `collisionCylinder`，保持原有局部变换/中心，只改变长度。
视觉焊丝始终保持55.941479mm，真实TCP、TCP标定、IK、ACCP方向约束、枪体V-HACD、
工件和碰撞过滤均未改变。缩短不是正式规划参数，也没有写回manifest。

| 缩短(mm) | IK候选 | WireCollision碰撞候选 | Workpiece碰撞候选 | 最终可行候选 | 视觉焊丝(mm) | 碰撞圆柱(mm) |
|---:|---:|---:|---:|---:|---:|---:|
| 0 | 144 | 144 | 144 | 0 | 55.941479 | 55.941479 |
| 3 | 144 | 0 | 85 | 16 | 55.941479 | 52.941479 |
| 5 | 144 | 0 | 85 | 16 | 55.941479 | 50.941479 |
| 10 | 144 | 0 | 85 | 16 | 55.941479 | 45.941479 |

计数单位为Point1中通过位姿/限位筛选的144个候选；碰撞候选按逐候选是否存在
对应碰撞pair统计，组件/工件面之间允许重叠计数。最终可行候选为原ACCP硬方向、
位姿、限位、焊接侧、碰撞筛选全部通过的Point1候选，不代表16点焊缝PASS。

结果文件：`comparison.csv`、`comparison.json`，每组目录含`summary.json`、
`point1_core.mat`、`pair_audit/collision_pairs.json`和Top10诊断。0mm是基线，
3/5/10mm只缩短临时碰撞圆柱；3mm以后焊丝不再撞工件，但仍有85个候选被枪体
凸组件撞工件拒绝，最终仅16个Point1候选可行。不能由此把缩短后的圆柱作为真实
焊丝安全模型，也不能直接生成或执行轨迹。

全部运行 `robot_motion=NO`，真实文件和正式场景未修改。
